# Repositories

Enzone uses the same extension model as upstream CloudStream. Add a repository URL (or shortcode) in:

**Enzone → Settings → Extensions → Add Repository**

## Extension lists

See the public wiki for an up-to-date [list of extensions](https://cloudstream.miraheze.org/wiki/List_of_extensions).

Community repositories that work with CloudStream generally work with Enzone because the package namespace remains `com.lagradost.cloudstream3`.

## Tips

- If repository JSON URLs fail to load, try a VPN — some ISPs block GitHub raw content.
- After adding a repository, open it and install the individual extensions you want.
- Then pick a provider from Home using the filter / None button.
