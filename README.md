# Enzone Docs

User and developer documentation for [Enzone](https://github.com/perspectivecomputing-source/enzone).

Built with [Retype](https://retype.com/) and published to GitHub Pages:

**https://perspectivecomputing-source.github.io/enzonedocs/**

## Local preview

Install Retype, then from this repo root:

```bash
retype start
```

## Deploy

Pushes to `master` build and deploy via [`.github/workflows/retype_build.yml`](.github/workflows/retype_build.yml).
